A propriedade position do CSS pode assumir os seguintes valores:

  • static - Este é o valor padrão. O elemento é posicionado de acordo com o fluxo normal do documento.
  • relative - O elemento é posicionado em relação a sua posição no fluxo normal do documento.
  • fixed - O elemento é posicionado em realção o viewport.
  • absolute - O elemento é posicionado em relação ao ancestral mais próximo.
  • sticky - O elemento varia entre relative e fixed dependendo da posição da rolagem.

A posição dos elementos é definida pelas propriedades top, bottom, left e right.
